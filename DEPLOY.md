# Ridgeline Rubbish Removal — Deploy Guide

## Before You Start

You'll need:
- A [GitHub](https://github.com) account
- A [Render](https://render.com) account
- A Google Maps API key (same one used for your other apps)

---

## Step 1 — Add the Logo

Copy your logo file into the static folder and rename it:

```
Ridgeline Rubbish Removal\static\logo.png
```

---

## Step 2 — Push to GitHub

1. Open GitHub Desktop (or GitHub.com)
2. Create a new repository called `ridgeline-rubbish-removal`
3. Add the entire `Ridgeline Rubbish Removal` folder as the repository root
4. Commit all files and push to GitHub

Your repo should contain:
```
app.py
requirements.txt
render.yaml
templates/
  login.html
  home.html
  quote.html
  quotes.html
  dashboard.html
  expenses.html
static/
  logo.png
```

---

## Step 3 — Deploy on Render

1. Go to [render.com](https://render.com) and log in
2. Click **New → Web Service**
3. Connect your GitHub repo `ridgeline-rubbish-removal`
4. Render will auto-detect the `render.yaml` — click **Apply**
5. Wait for the build to complete (2–3 minutes)

---

## Step 4 — Set Environment Variables

In Render → your service → **Environment**, add:

| Key | Value |
|-----|-------|
| `APP_PASS` | Your chosen password (e.g. `ridgeline2024`) |
| `GOOGLE_MAPS_KEY` | Your Google Maps API key |

`APP_USER` defaults to `admin`. Change it here if you want a different username.

`SECRET_KEY` is auto-generated by Render — leave it as is.

---

## Step 5 — Add the Persistent Disk

The app stores quotes, expenses, and photos in a `data/` folder that must survive deploys.

In Render → your service → **Disks**, add:

| Field | Value |
|-------|-------|
| Name | `data` |
| Mount Path | `/opt/render/project/src/data` |
| Size | 1 GB |

Click **Save** — Render will redeploy automatically.

---

## Step 6 — Log In

Your app is live at the URL Render provides (e.g. `https://ridgeline-rubbish-removal.onrender.com`).

Default login:
- **Username:** `admin`
- **Password:** whatever you set for `APP_PASS`

---

## Google Maps API Key Setup

If you don't have a key yet:

1. Go to [console.cloud.google.com](https://console.cloud.google.com)
2. Create a project → Enable **Maps JavaScript API** + **Places API** + **Distance Matrix API**
3. Create an API key under **Credentials**
4. Restrict it to your Render domain for security

---

## Updating the App

Any time you make changes:
1. Edit the files locally
2. Commit and push to GitHub
3. Render auto-deploys within 2–3 minutes

Your data (quotes, expenses, photos) is on the persistent disk and is never affected by redeploys.
